Bus Tracking and Management System

About the Project:
This is a C++ project I developed to make basic bus management easier. It allows users to add bus details, manage routes, update bus locations, and check the status of buses through a simple menu.

I created this project to practise  our C++ programming skills and understand how Object-Oriented Programming (OOP) can be used in a real-world example.

Features:

- Add and view bus details
- Search for a bus using its details
- Assign routes to buses
- Update the current bus location
- Track bus information
- View route details
- Check for nearby buses
- Update driver and conductor information
- Change the bus status
- Delete bus records
- Save bus information using file handling

Technologies Used:

- C++
- Object-Oriented Programming (OOP)
- Classes and objects
- Inheritance and polymorphism
- Vectors
- File handling

OOP Concepts Used:

- Encapsulation: I used classes to keep related data and functions together.
- Abstraction: I used an abstract "Person" class to define common behavior for staff.
- Inheritance: The "Driver" and "Conductor" classes inherit from the "Person" class.
- Polymorphism: Virtual functions allow derived classes to implement their own behavior.

What we Learned

While working on this project, I got practical experience with classes, inheritance, virtual functions, vectors, and file handling. I also learned how to organize a program into different functions and create a menu-driven application.
